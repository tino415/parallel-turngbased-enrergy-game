Prototype rules

Nodes start with active and invested energy. Invested principal is locked and earns 10% in active energy. Active energy decays 10% each round. Each node naturally generates 1 active energy. Energy transfers only across one edge. Each node may issue one order. Attacks are grouped by destination and attacker, then shuffled; attack power uses an independent ±20% modifier for each combatant. Captured nodes lose a random 25–75% of investment. The player owning more nodes after round 20 wins.
